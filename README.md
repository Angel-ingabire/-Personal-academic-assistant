# Student Academic Platform 

A mobile application designed for African Leadership University (ALU) students to help them manage academic responsibilities, track assignments, schedule classes, and monitor attendance throughout the semester.

##  Problem Statement
ALU students often struggle with:
- Tracking assignments and deadlines
- Remembering academic schedules
- Monitoring attendance and academic engagement

This leads to missed deadlines, poor attendance, and academic stress.

##  Solution
The Student Academic Platform acts as a **personal academic assistant**, helping students:
- Organize coursework
- View daily and weekly schedules
- Track assignments and attendance
- Receive alerts when academic engagement is at risk

## Core Features
- Dashboard overview
- Assignment management
- Academic session scheduling
- Attendance tracking and alerts
